	I3 + If + I5 + I4 = Is
	Is = I5 - I4 - I5
	Is = 4 - 3 - 5
	Is = -4A

	1.10/ Exercices à résoudre

Exercice 1 :

q=50C dans un circuit pendant 10s t=10s
Calcul de I

I = q/t = 50/10 = 5A

7200C durand 1h

I = 7200/3600 = 2A

1Ah durant 5min

C = I/t  = 1/(5/60) = 12C


Exercice 2 :

Calcul de l'intesité I0 sachant que : I1 = -6A, I2 = 4A, I3 = 5A, I4 = -3A, I5 = 2A
I0+I4+I5+I3 = I1+I2
I0 = I1 + I2 - I3 - I4 - I5
I0 = -6+4-5+3-2 = -6A

Exercice 3 :

Ia=2A, Ib=-3, Ic=1A

I1 : I1 = Ic+Ia => I1 = 1+2 = 3A
I2 : I2 + Ia + Ib = 0 => I2 = -Ia -Ib = -2+3 = 1A
I3 : I3 + Ic = Ib => I3 = Ib-Ic = −3−1 = -4A
